# ばしょを きいて、かくにんしましょう

育成就労用OL授業⑧午前の、教師が画面共有して操作する位置確認教材です。

教材の基準：採用済みPowerPoint `lesson8_48slides_UDDigiKyokashoN_40pt_shelf4_items_opaque_final(2).pptx`。スライド本体は変更しません。

## 授業モード

- きほんの ばしょ：うえ・した・まえ・うしろ・よこ・なか
- たな・ロッカー：いちばんうえ／した、うえから／したから○ばんめ
- おく・てまえ：作業台の天板上の奥・手前

学習者は指示を聞き、「○○の｛ばしょ｝ですね」と確認し、候補番号を伝えます。教師が配置を操作します。

HTML、画像、問題データ、操作方法はこのリポジトリに追加します。
